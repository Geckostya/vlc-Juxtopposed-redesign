Third preview of the VLC community redesign for Windows x64, built on VLC 4.0-dev.

Download **vlc-redesign-0.3.0-win64.zip**, unzip it and run `vlc.exe`.

### New since 0.2.0
- Music player with cover art and track information.
- Compact player window with an independently opened library, nested video folders, compact sidebar and pinned library locations.
- Separate sorting and view menus with saved grid/list preference.
- Profiles for theme, controls, VLC options and playback/effect settings; customization of both top and control bars.
- Named playback/effect presets, native audio visualizer and available HDR tone-mapping controls.
- SRT/WebVTT synchronization timeline, external subtitle/audio pairing for files and collections, without duplicate tracks.
- Library favorites, playlist membership, rename/delete/export, and native stream/convert actions.
- Fixes for Advanced Options binding loops, equalizer initialization, hidden/pinned controls, missing thumbnails and compact layouts.

### Validation and limitations
Native Windows build; 72 integration assertions passed in an isolated offscreen runtime, all 106 QML files parsed successfully. Physical HDR/DirectComposition playback, sound quality and live network sources were not exercised by offscreen tests. HDR controls expose capabilities actually available in VLC. Library folder management uses native indexing and File Explorer.

### Notes
- Preview based on VLC 4.0-dev.
- Settings use `%APPDATA%\vlc`, shared with other VLC installations. Back up existing settings if needed.
- Classic interface: `vlc.exe --no-qt-redesign`.
- Automatic update checks are disabled in this build.
